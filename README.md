# Yeşil Mühendis – Günlük Bilgi Kartları

KGK Kurumsal Sürdürülebilirlik Raporlama Uzmanlığı sınavı adayları için günlük bilgi kartı görselleri (TSRS 1, TSRS 2, Kurul kararları).

- `kartlar/` – Instagram'da paylaşılan 1080×1350 PNG kartlar
- `scripts/render_card.py` – kart tasarımını PNG'ye çeviren betik
